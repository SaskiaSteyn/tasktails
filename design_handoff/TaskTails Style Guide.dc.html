SPACING SCALE
4-based, tight. Common gaps: 6 · 8 · 10 · 14 · 16. Screen padding 16–24. Layout uses flex/grid + gap, never per-element margins.

Icons are flat CSS shapes — circles, rounded rectangles, diamonds (45°-rotated squares) and CSS-border triangles. No detailed illustration. Coins = amber circle + lighter ring; checkmark = rotated 2px border-corner; ears = border triangles. Pets are built from the same primitives (head circle, triangle ears, dot eyes, border-arc mouth). Keep colour never the sole signal — always pair with text or an icon (WCAG AA).
